# Pearl AI — LINE Auto-Reply Bot

น้องเพิล — ผู้ช่วย AI ตอบแชท LINE ของร้านคุณ ทำงาน 24 ชั่วโมง — โค้ดประกอบเล่ม **"Automate ด้วย AI + API #01 · LINE ตอบแชทอัตโนมัติ"** โดย Work With AI Lemon

ตอบคำถามซ้ำของลูกค้าจากคู่มือร้านของคุณเอง · ตอบแบบ reply ไม่กินโควตา LINE · กันพลาด 3 ชั้นไม่ให้แอบอ้างราคา · จดบันทึกทุกบทสนทนา แจ้งเตือนเมื่อมีเรื่องส่งต่อ และสรุปยอดให้เจ้าของร้านทุกคืน

## ต้องมีอะไรก่อน

- Python 3.10 ขึ้นไป ([python.org](https://www.python.org))
- บัญชี LINE Developers (ฟรี — [developers.line.biz](https://developers.line.biz))
- บัญชีสมอง AI อย่างใดอย่างหนึ่ง (เริ่มหลักสิบบาท)
  - กรณีที่ 1 · เช่าตรง เช่น [Anthropic](https://www.anthropic.com)
  - กรณีที่ 2 · ผ่านคนกลาง [OpenRouter](https://openrouter.ai) — คีย์เดียวสลับโมเดลได้ทุกค่าย
- ร้านที่มีลูกค้าทักแชทจริง (ระบบนี้เก่งเรื่องคำถามซ้ำ — ร้านที่ยังไม่มีใครทัก ยังไม่ต้องมี)

## ติดตั้ง 6 ขั้น (ราว 20 นาที ตามบทที่ 3 และ 8 ของเล่ม)

```bash
# 1) โคลนและติดตั้ง
git clone https://github.com/workwithai-th/Pearl-AI-line-bot.git
cd Pearl-AI-line-bot
pip install -r requirements.txt

# 2) สร้างไฟล์กุญแจจากตัวอย่าง แล้วเติมค่าจริง
cp .env.example .env
```

3) ที่ [developers.line.biz](https://developers.line.biz) สร้าง Provider → สร้าง Channel แบบ **Messaging API** → คัดลอก **Channel secret** และ **Channel access token** ใส่ใน `.env` (ปิด "ข้อความตอบกลับอัตโนมัติ" ในหน้าตั้งค่าด้วย กันตอบซ้ำสองระบบ)

4) เติมคีย์สมอง AI ใน `.env` — กรณีที่ 1 ใส่คีย์ผู้ให้บริการแล้ว `AI_PROVIDER=anthropic` · กรณีที่ 2 ใส่คีย์ `sk-or-...` แล้ว `AI_PROVIDER=openrouter`

5) แก้ไฟล์ `persona.txt` (ตัวตนผู้ช่วยของร้าน) และ `shop-knowledge.md` (คู่มือร้าน — เมนู ราคา กติกา คำถามยอดฮิต) ให้เป็นของร้านคุณ แล้วอัปเดตวันที่บนหัวไฟล์ทุกครั้งที่แก้

6) รันและเปิดอุโมงค์ทดสอบ (แยกหน้าต่างกัน)

```bash
python app.py
# หน้าต่างที่สอง — ดาวน์โหลด cloudflared จาก developers.cloudflare.com ก่อน
cloudflared tunnel --url http://localhost:8000
```

คัดลอกที่อยู่ `https://xxxx.trycloudflare.com` ที่ขึ้นมา ไปวางที่ **Webhook URL** ในหน้าตั้งค่า Messaging API (ต่อท้ายด้วย `/webhook`) กด Verify → ทักร้านจากมือถือได้เลย

## ขึ้นระบบจริง 24 ชั่วโมง (บทที่ 11)

push ขึ้น git (ส่วนตัว) แล้วสร้าง Web Service บน [Render](https://render.com) แผนฟรี — Build command ว่าง / Start command ว่า `python app.py` / ตั้งตัวแปรสภาพแวดล้อมตาม `.env.example` ทั้งหมด แล้วอัปเดต Webhook URL เป็นที่อยู่ถาวร + `/webhook` — เคล็ดลับ ตั้งเว็บเฝ้าให้เข้า `/health` ทุกสิบนาที ช่วยปลุกระบบแผนฟรี

ค่าใช้จ่ายต่อเดือนของร้านเล็ก: LINE 0 บาท (ตอบด้วย reply) + สมอง AI หลักสิบบาท + โฮสต์ 0 บาท

## เก็บรหัสเจ้าของร้าน (BOSS_ID — บทที่ 10)

ทักร้านหนึ่งครั้งจากมือถือ โดยเพิ่มบรรทัดนี้ท้ายลูปใน webhook ชั่วคราว รัน ทัก แล้วอ่านค่าจากหน้าจอ:

```python
print("BOSS_ID =", user_id)
```

คัดลอกค่าใส่ `BOSS_ID` ใน `.env` — จากนี้ทุกเรื่องส่งต่อจะเด้งหาคุณทันที และคุณพิมพ์คำเดียวว่า **สรุป** ในแชทเพื่อรับรายงานประจำวัน

## ดูแลระบบ (บทที่ 12)
